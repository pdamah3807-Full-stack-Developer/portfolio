## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/pdamah3807-Full-stack-Developer/portfolio.git
```

### 2. Open the project

```bash
cd portfolio
```

### 3. Run locally

You can either:

- Open `index.html` directly in your browser, or
- Run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
